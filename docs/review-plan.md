## 3. Критерии проверки (чек-лист)

### 3.3. Производительность
- [ ] Использование стандартных оптимизированных методов Django ORM.

### 3.4. Читаемость и стиль
- [ ] Соответствие кода стандартам PEP 8 (стиль Python).
